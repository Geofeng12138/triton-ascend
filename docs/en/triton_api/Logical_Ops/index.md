# Logical Operations

| API | Brief Description |
|--|--|
| [and](./and.md) | Logical AND operation |
| [or](./or.md) | Logical OR operation |
| [not](./not.md) | Logical NOT operation |
| [logical_and](./logical_and.md) | Performs element-wise logical AND operation on two tensors |
| [logical_or](./logical_or.md) | Performs element-wise logical OR operation on two tensors |
| [not](./not.md) | Inverts the bits of tensor values. |
| [invert](./invert.md) | Flips each bit of the tensor values. |
| [lshift](./lshift.md) | Shifts the tensor values to the left by a given amount. |
| [rshift](./rshift.md) | Shifts the tensor values to the right by a given amount. |
| [xor](./xor.md) | Computes the XOR value of two elements. |
